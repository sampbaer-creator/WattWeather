DEPLOYED GITHUB PAGES EDITION

The live path is static.

No ASP.NET server or Blazor WebAssembly runtime is deployed on GitHub Pages. The browser loads static files and requests public data directly.

  1. GitHub Pages serves static HTML, CSS, JavaScript, and the non-sensitive EIA JSON snapshot.
  2. Open-Meteo receives browser requests for city search, current weather, forecasts, solar conditions, and historical temperature.
  3. U.S. EIA data is refreshed by a scheduled workflow using a protected repository secret. The secret is never sent to the website.
  4. Personal energy records remain in browser localStorage and are processed in the browser.
  5. Charts and estimates are generated locally and labeled as associations or estimates, not guaranteed causes.
DATA SOURCES & LIMITS

What feeds each result?

Open-Meteo

City geocoding, current conditions, seven-day forecasts, solar radiation, and historical daily temperature.

View source documentation →

U.S. EIA

Statewide residential electricity price, customers, and sales. WattWeather derives average monthly household usage from annual sales and customer counts.

View EIA Open Data →

User utility records

Optional cost and kWh records entered manually or imported from CSV. They stay in the current browser unless the user clears browser storage.

Important limitation

Public electricity values are statewide averages. City weather provides local climate context, but city-level household meter data is not publicly available.

AVAILABLE IN THE REPOSITORY · NOT THE PAGES RUNTIME

The additional .NET architecture.

The repository also demonstrates C#, .NET MAUI, Blazor, SQLite, Entity Framework Core, dependency injection, typed HTTP services, repositories, testing, statistics, and forecasting. This work is real, but it is separate from the static GitHub Pages runtime.

Core

Domain models, validation, statistical calculations, anomaly detection, degree days, and forecasting safeguards.

Infrastructure

SQLite persistence, Entity Framework Core, repository implementations, API integration, and repeatable initialization.

Applications

A cross-platform .NET MAUI client and a Blazor web project consume the shared domain and infrastructure layers.

Tests

Deterministic tests cover validation, calculations, anomaly behavior, repositories, and database initialization without requiring live APIs.

Not currently live:

No secure ASP.NET backend, DSIRE integration, IRS guidance, solar financial-suitability screening, account system, or notification service is deployed.
